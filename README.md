# RobbinBooks

Landing page for RobbinBooks, a sports analytics subscription service that delivers positive expected value (+EV) betting picks. It explains +EV betting, includes an interactive EV calculator with a variance simulation, and showcases verified results and member testimonials.

## Stack

Vanilla HTML, CSS, and JavaScript. No build tools, no framework, no dependencies. The only external request is Google Fonts.

## Project structure

```
RobbinBooks/
├── index.html      # page markup and copy
├── styles.css      # layout and theming
├── script.js       # rendering, EV calculator, simulation, lightbox
├── data.js         # links, stats, screenshots, testimonials
├── images/         # result screenshots
└── README.md
```
